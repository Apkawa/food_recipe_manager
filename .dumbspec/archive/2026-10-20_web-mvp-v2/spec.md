# 2026-10-20_web-mvp-v2: MVP-прототип интерфейса калькулятора еды

**Created:** 2026-10-20T17:10:12+03:00

## Scope
- В scope: прототип (mockup) удобного и красивого интерфейса **калькулятора еды** — то есть инструмента ресейлинга рецептов: порции, количество ингредиентов (исходное → целевое), чеклист «что уже добавлено». **Только верстка, без логики.**
- **Продолжение (v2):** mockup отражает рабочий цикл: вставленный текст рецепта → разобранный рецепт → **правка количества любого продукта → пропорциональный пересчёт всего**. Переосмысление перегруженного текущего интерфейса (таблица «Ингредиент | Значение | Ед. изм. | Изменить», два независимых инпута порций, раскрытая textarea на пол-экрана): **без таблицы, без кнопок «Изменить», без лишних полей**.
- Файлы: `apps/web-mvp-v2/index.html` + `apps/web-mvp-v2/style.css`.
- Один HTML-файл, без React, Tailwind CSS через **CDN (Play CDN)**.
- Верстка респонсивная: переключение между мобильным и десктопным видом на лету (breakpoints), без перезагрузки.
- Тема: **тёмная + светлая** с переключателем (только визуальный).
- Текущая логика калькулятора и расположение его элементов **игнорируются** — свободный дизайн.
- Out of scope: рабочая логика, состояние, вычисления, React/фреймворки, сборка, интеграция с existing-приложениями, КБЖУ/калории (их нет в домене проекта).

## Approach
- Статичный mockup с реалистичными decorative-данными: рецепт с именем, исходными и целевыми порциями, список ингредиентов с весами/единицами (исходное → пересчитанное) и чекбоксы-зачёркивания.
- Tailwind Play CDN одним `<script>` в `<head>`; `style.css` — для того, что не покрывается утилитами (тонкая полировка, scrollbar, шрифтовые детали).
- Респонсив через Tailwind-брейкпоинты: мобильный — компактный одноколоночный flow; десктоп — две колонки (состав слева, панель итогов/ресейлинга справа, липкая).
- Ключевые блоки макета (v5 — компактность, порядок сверху вниз):
  - Шапка (v8): верхний ряд = **гамбургер (тумблер сайдбара) слева** + eyebrow, справа — «Поделиться», «В избранное» (переключатель темы в шапке нет); под ним заголовок на всю ширину. Гамбургер **всегда виден** (v8). **Без** мета-строки и стрипа шагов (v4).
- **Левый сайдбар (v7, v8)**: меню «Калькулятор» (активен), «Избранное», «О проекте»; в самом низу — **переключатель темы**. На широких экранах (lg+) — открыт по умолчанию (фиксированная левая колонка 288px, контент с отступом слева), но **закрывается по гамбургеру** (контент при этом занимает всю ширину) и снова открывается (v8); на узких — drawer слева (backdrop, крестик закрытия).
  - **Список ингредиентов первым** (v5): **каждый раздел — одна карточка** (заголовок внутри, rows через divide-y, py-2.5, чекбокс h-6, количество inline `s + b`, **кнопка-карандаш 44px / иконка 20px** — как в v3, v5). Любая строка редактируема; одна показана в состоянии «редактируется» (яйца: 3 → 1, input-поле, карандаш → «сохранить»).
  - **«Описание» — всегда открытая карточка** (не аккордеон, v4) — после ингредиентов (v5).
  - **Ресейл-бар (единственный контрол порций) — после описания (v5)**: «Готовим на N порций» (стайлер −/+), «из 7 в оригинале» (read-only из парсинга), бейдж «×0.33 · под 1 яйцо», хинт про карандаш, прогресс «N из M добавлено» + «Сбросить».
  - Список ингредиентов: **каждый раздел — одна карточка** (заголовок внутри, rows через divide, плотные py-2.5); строка = чекбокс + название + количество (исходное — мелкое зачёркнутое inline, текущее — акцентное) + **кнопка-карандаш** (40px). Любая строка редактируема; одна показана в состоянии «редактируется» (яйца: 3 → 1, input-поле, карандаш → «сохранить»).
  - Аккордеон «Исходный текст» (единственный оставшийся `<details>`) — **textarea с вставленным текстом + кнопка «Разобрать рецепт»** (так вставляется текст).
  - Мобильный sticky-bottom бар: порции, бейдж, прогресс, −/+.
- Дизайн: современная «еда-friendly» эстетика, тёплые акценты, чёткая иерархия, крупные тач-таргеты на мобильных.
- Тема: Tailwind `class`-стратегия dark mode; переключатель — визуальный (без JS-логики переключения, либо минимальный инлайн-JS только для смены класса — это допустимо как «верстка», если не затрагивает логику калькулятора).

## Constraints
- `apps/web-mvp-v2/` **не существует** — создаётся с нуля.
- Домен проекта: ресейлинг рецептов (порции, quantity, units, strikethrough checklist). **Нет** данных о калориях/БЖУ — их в mockup не показывать.
- Единицы в домене: l, ml, kg, g, tsp, tbsp, cup, shot, pinch, pcs, portion, taste.
- Core не имеет build-шага (apps импортируют `src/` напрямую) — для mockup не релевантно, но подтверждает: mockup автономный, не зависит от core.
- Tailwind подключается только через CDN — build-шага нет.

## Open questions
- none (авторитетно решено автономно: блоки макета как в Approach; переключатель темы — минимальный инлайн-JS только для смены класса).
